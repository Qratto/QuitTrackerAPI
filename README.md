# Quit Tracker API

REST API для отслеживания отказа от вредных привычек.

## Стек

- Python 3.13
- FastAPI
- SQLAlchemy (async) + asyncpg
- PostgreSQL
- Pydantic

## Возможности

- Создание, редактирование, просмотр привычек которые бросаешь
- Отметка срывов с датой и заметкой
- Расчёт текущей серии и рекорда 
- Удаление привычки вместе со всеми срывами

## POST /habits

Создать привычку, которую бросаешь.

**Тело запроса**

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `name` | `string` | да | Название привычки |
| `description` | `string` | нет | Описание |

**Пример запроса**

```bash
curl -X POST http://localhost:8000/habits \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Курение",
    "description": "Бросить окончательно"
  }'
```

**Пример ответа**

HTTP code 201

```json
{
  "id": 1,
  "name": "Курение",
  "description": "Бросить окончательно",
  "started_at": "2026-09-01T00:00:00Z",
  "created_at": "2026-09-01T00:00:00Z"
}
```

**Возможные ошибки**

- `422 Unprocessable Entity` — невалидное тело запроса (отсутствует `name`)

## POST /habits/{habit_id}/relapses

Отметить срыв — момент, когда не удержался.
Запись сохраняется с текущим временем UTC, если `occurred_at` не передан.

**Параметры пути**

| Параметр | Тип | Описание |
|---|---|---|
| `habit_id` | `integer` | ID привычки, к которой относится срыв |

**Тело запроса**

| Поле | Тип | Обязательно | Описание |
|---|---|---|---|
| `occurred_at` | `datetime` (ISO 8601) | нет | Когда произошёл срыв. По умолчанию — текущее время UTC |
| `note` | `string` | нет | Свободная заметка |

**Пример запроса**

```bash
curl -X POST http://localhost:8000/habits/1/relapses \
  -H "Content-Type: application/json" \
  -d '{
    "occurred_at": "2026-09-21T12:00:00Z",
    "note": "Стресс на работе"
  }'
```

**Пример ответа**

HTTP code 201

```json
{
  "id": 5,
  "habit_id": 1,
  "occurred_at": "2026-09-21T12:00:00Z",
  "note": "Стресс на работе",
  "created_at": "2026-09-21T12:05:33.123456Z"
}
```

**Возможные ошибки**

- `404 Not Found` — привычки с таким id нет
- `422 Unprocessable Entity` — невалидный формат `occurred_at`

## GET /habits/{habit_id}/stats

Статистика по привычке: текущая серия, рекорд, количество срывов.

**Параметры пути**

| Параметр | Тип | Описание |
|---|---|---|
| `habit_id` | `integer` | ID привычки |

**Как считается**

Серия — это интервал между соседними событиями. Точки на шкале времени: `started_at`, каждый `occurred_at` срыва, текущее время. `current_streak` — последний интервал, `longest_streak` — максимум по всем интервалам.

**Пример запроса**

```bash
curl http://localhost:8000/habits/1/stats
```

**Пример ответа (срывов нет)**

HTTP code 200

```json
{
  "habit_id": 1,
  "name": "Курение",
  "started_at": "2026-09-01T00:00:00Z",
  "last_relapse_at": null,
  "current_streak_days": 33,
  "longest_streak_days": 33,
  "relapse_count": 0
}
```

**Пример ответа (был один срыв)**

HTTP code 200

```json
{
  "habit_id": 1,
  "name": "Курение",
  "started_at": "2026-09-01T00:00:00Z",
  "last_relapse_at": "2026-09-21T12:00:00Z",
  "current_streak_days": 13,
  "longest_streak_days": 20,
  "relapse_count": 1
}
```

Разбор примера выше:

- 1 сентября → 21 сентября: 20 дней (рекорд)
- 21 сентября → сейчас: 13 дней (текущая серия)
- `longest_streak_days` = 20 — рекорд сохраняется, даже если серия обнулилась

**Возможные ошибки**

- `404 Not Found` — привычки с таким id нет
